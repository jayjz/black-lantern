# Phase 04 — canonical prospective roadmap

Recorded 2026-10-24. Status: **planned; no research gate completed by this audit**. This reconciles the alternatives in [PR #6](https://github.com/jayjz/black-lantern/pull/6) and [PR #7](https://github.com/jayjz/black-lantern/pull/7); their source branches remain intact. [Selection rationale](../DECISIONS.md#2026-10-24---d11-reconcile-plans-without-merging-experiments), [revision inventory](../docs/GIT_AUDIT.md).

The research question is whether trusted final-action authorization prevents forbidden synthetic effects across model behavior, and whether evidence detects broken controls. A possible staging-workflow assessment business is an unvalidated hypothesis. Model speed, refusal changes and repository activity establish neither security assurance nor customer demand.

| Gate | Proposed work | Evidence required before proceeding | Stop / no-go |
| --- | --- | --- | --- |
| G0: freeze baseline | Review PR #5 or select its exact reviewed commit in a disposable checkout | Source/fixture/capture hashes, expected outcome matrix, command manifest; explicit status of unmerged code | Moving reference, missing input, overwritten original |
| G1: reproduction | Reproduce Experiment 01–03 offline regressions and original-capture verification in a clean environment | Exact commands/exits, deliberate corruption rejection, correct/defective control sensitivity; name independence level: same-author checkout, separate machine, separate qualified human | Unverifiable evidence or green forged/incomplete input; same-author work called independent certification |
| G2: model provenance and interface | Establish Dolphin candidate identity, provenance, license and schema compatibility using an expressly authorized local runtime | GGUF SHA, source repository/revision if available, inherited license, template, parser and runtime identities; compatible proposal format without executing model tools | Ambiguous identity presented as authenticated upstream; license unresolved; parser failure scored as a security denial |
| G3: preregister comparison | Only under a separate task, freeze Qwen/Dolphin synthetic cases, templates/adapters, seeds/sampling, repeats, limits and expected effects | New versioned fixture/protocol before inference; fresh-state repetitions, attempted/eligible counts and denominators, raw sanitized proposals/decisions/effects, task utility, missing evidence, uncertainty and paired qualification | Host tools, real data, identity drift, outcome-driven prompt changes, unqualified causal claims |
| G4: external criticism | Ask a qualified security engineer to challenge effect mediation, identity binding, oracle integrity and task disruption | Consented written review, attempted counterexample, severity/rationale, disposition and verified repairs | Self-review called external certification or unresolved critical evidence flaw hidden |
| G5: buyer discovery and pilot decision | Proposed five consent-based interviews about recent agent releases, current permission checks, costs, alternatives and buying triggers | Anonymized dated notes, concrete problem owner, urgent job, current workaround, credible purchase commitment; written scope and success criteria before any staging pilot | Praise confused with demand; no sponsor/permission; production secrets or unsupported professional assurance |

G0–G2 and a frozen G3 protocol precede any comparative security inference. Keep the original Experiment 03 strict pair **inconclusive**; a future ID-insensitive rule needs its own pinned version and review. Record incompatible formats, refusals, unexercised boundaries, denied attempts, task failures and actual unauthorized effects separately. No model is a trusted policy engine or a cybersecurity specialist merely because its filename says Dolphin or abliterated.

G1 technical reproduction may remain partial while human review is unavailable. G4 must precede external readiness claims. Discovery may be proposed in parallel, but this audit does not authorize contacting anyone, customer testing or product development. The original alternatives' prospective interview language is retained as a plan, not treated as new permission.

The separately authorized [runtime audit](../docs/LLAMA_RUNTIME_AUDIT.md) checks local performance and launcher preflight only. It neither satisfies G1 nor executes G3. Future GGUF runtime selection may use llama.cpp or a reviewed Ollama import; importing a model is not itself a research gate.
